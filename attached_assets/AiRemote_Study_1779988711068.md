## أولاً: نظرة عامة على المشروع الحالي (الإرث — MoclawRemote V1)

### ما هو المشروع؟
نظام وصول عن بُعد مخصص لأجهزة Windows، يعتمد على ثلاثة محاور تقنية أساسية:

| المحور | التقنية المستخدمة | الغرض |
|--------|-------------------|-------|
| النفق الشبكي | Bore Tunnel | كشف منفذ SSH المحلي (22) للإنترنت العام |
| الإشعارات | Telegram Bot API | إرسال بيانات الاتصال تلقائياً عند الاتصال |
| التوثيق | SSH Keys (ED25519) | تأمين الاتصال ومنع الوصول غير المصرح |

### آلية العمل الحالية
1. يُشغّل المستخدم `start_tunnel_v1.bat` على الجهاز البعيد
2. يفتح `bore.exe` نفقاً يربط المنفذ 22 بخادم `bore.pub` العام
3. يُرسل السكريبت بيانات الاتصال عبر Telegram
4. يتصل المسؤول عبر SSH: `ssh -i moclaw_key [USER]@bore.pub -p [PORT]`
5. عند الانقطاع يُعيد النفق الاتصال تلقائياً

### نقاط القوة في V1
- ✅ بسيط وخفيف — لا يحتاج خادماً خاصاً
- ✅ إعادة الاتصال التلقائية عند الانقطاع
- ✅ إشعارات فورية عبر Telegram
- ✅ تأمين بمفاتيح SSH

### نقاط الضعف (دوافع التطوير)
- ❌ Windows فقط — لا دعم لـ Linux
- ❌ لا واجهة مستخدم — يعتمد على سطر الأوامر
- ❌ لا لوحة تحكم مركزية للأجهزة
- ❌ لا نظام مستخدمين أو صلاحيات
- ❌ بيانات حساسة مدمجة داخل السكريبت
- ❌ لا سجل للجلسات أو الاتصالات
- ❌ اعتماد كامل على bore.pub الخارجي وغير المستقر

## ثالثاً: المنافسون العالميون وتحليل الفجوة

| المنتج | نقاط قوته | ما يتفوق عليه AiRemote |
|--------|-----------|------------------------|
| **TeamViewer** | سهل جداً، دعم شامل | مغلق المصدر، ثقيل، مكلف، لا AI |
| **AnyDesk** | سريع وخفيف | مدفوع للاستخدام التجاري، لا AI |

### الفجوة التي يملؤها AiRemote
> المشروع الوحيد في السوق الذي يجمع **Remote Access + AI Agent مدمج** في أداة مفتوحة المصدر، بواجهة حديثة، تعمل على Windows/Linux والموبايل، عبر الإنترنت أو الشبكة المحلية تلقائياً، مع نظام اتصال متعدد الطبقات يضمن أقصى استقرارية.

```
┌──────────────────────────────────────────────────────┐
│              AiRemote Connection Engine              │
│                                                      │
│  الأولوية 1: AiRemote Relay (خادم خاص بالمشروع)   │
│  الأولوية 2: Cloudflare Tunnel (مجاني وموثوق)      │
│  الأولوية 3: ngrok (احتياطي)                        │

│  الأولوية 5: LAN Direct (إذا على نفس الشبكة)       │
│                                                      │
│  → يختار الأفضل تلقائياً ويتحول عند الانقطاع      │
└──────────────────────────────────────────────────────┘
```

### AI Agent المدمج — آلية العمل

```
المستخدم يكتب: "ما استخدام المعالج الآن؟"
         ↓

         ↓
  يستقبل النتيجة الخام
         ↓
  يُحللها ويشرحها بلغة بشرية
         ↓
المستخدم يرى: "المعالج يعمل بنسبة 34%، معظمها من عملية X"

### المكدس التقني الكامل (Tech Stack)

| الطبقة | التقنية | السبب |
|--------|---------|-------|
| **Agent (Windows/Linux)** | Electron + TypeScript | واجهة رسومية أصيلة على الأنظمة |
| **Backend Server** | Node.js + TypeScript + Fastify | سريع وخفيف وموحد |
| **Web Dashboard** | React + TypeScript + TailwindCSS | احترافي وسريع التطوير |
| **Mobile App** | React Native + TypeScript | كود موحد لـ Android وiOS |
| **AI Engine** | OpenAI API / Local LLM | فهم الأوامر وتنفيذها وتشخيصها |
| **قاعدة البيانات** | SQLite (self-hosted) / PostgreSQL (cloud) | مرونة بحسب البيئة |
| **التوثيق** | SSH Keys + JWT Tokens | أمان عالٍ وقياسي |
| **الاتصال الأساسي** | AiRemote Relay (WebSocket) | مستقر ومتحكم فيه |
| **الاتصال الاحتياطي** | Cloudflare Tunnel + ngrok + Bore | طبقات استقرارية متعددة |
| **الإشعارات** | Telegram + Push Notifications | إخطار فوري |

## عاشراً: التوصيات والملاحظات الختامية

1. **AI Agent هو الميزة الأهم** — لا يوجد منافس مفتوح المصدر يقدمها، وهذا ما سيجعل الناس تتحدث عن المشروع
2. **Multi-tunnel Engine** — حل استقرار الاتصال هو الشكوى الأكبر في كل أدوات الوصول عن بُعد
3. **TypeScript للكل** — يضمن توحيد الكود وتقليل الأخطاء ويسهّل مساهمة المجتمع
4. **Docker من اليوم الأول** — يجعل self-hosted سهلاً وسريعاً
5. **دعم العربية في AI** — سوق عربي ضخم ومهمل تماماً في هذا المجال، وهذا ميزة تنافسية حقيقية
6. **الأمان أولوية وليس إضافة** — خصوصاً في AI Agent الذي ينفذ أوامر حقيقية على أجهزة حقيقية

## حادي عشر: فهم البنية الكاملة للمنظومة

### ما الذي يحققه V1 وما الذي ينقصه؟

V1 الحالي هو **فقط الجزء المثبَّت على الجهاز البعيد**، ولا يمثّل المنتج الكامل:

| الجزء | الوصف | حالته في V1 |
|-------|-------|-------------|
| Agent (الجهاز البعيد) | يفتح النفق وينفذ الأوامر | ✅ موجود جزئياً |
| السيرفر المركزي | يدير الاتصالات ويشغّل AI | ❌ غير موجود |
| واجهة التحكم + AI Chat | ما يراه ويستخدمه المتحكم | ❌ غير موجود |

### المنظومة الكاملة المطلوبة

```
┌─────────────────┐         ┌──────────────────┐        ┌──────────────────┐
│  الجهاز البعيد  │         │  السيرفر المركزي  │        │  أنت (المتحكم)  │
│  (Agent)        │◄───────►│  Relay + AI       │◄──────►│  Dashboard/Chat  │
│                 │  نفق    │                  │  واجهة │                 │
│ • Agent مثبَّت  │  مشفّر  │ • يدير الاتصال   │  شات   │ • تكتب بالعربي  │
│ • يفتح النفق   │         │ • يشغّل AI        │        │ • AI يفهمك      │
│ • ينفذ الأوامر │         │ • يوجّه الأوامر  │        │ • ترى النتائج   │
└─────────────────┘         └──────────────────┘        └──────────────────┘
     ✅ موجود في V1              ❌ يُبنى من الصفر           ❌ يُبنى من الصفر
```

           ↓
     السيرفر يُرسل الأمر للـ Agent
     على الجهاز البعيد عبر النفق
           ↓
     Agent ينفذ الأمر ويُعيد النتيجة
           ↓
     AI يُحلّل النتيجة ويردّ عليك:
     "هناك 47 عملية نشطة، أبرزها:
      Chrome يستهلك 34% من الذاكرة..."
```

### الفرق بين الوضع الحالي وAiRemote V2

| العنصر | الوضع الحالي (V1 + Claude يدوياً) | AiRemote V2 |
|--------|-----------------------------------|-------------|
| من يفهم الطلب؟ | Claude خارجي | AI مدمج داخل التطبيق |
| من يتصل بالجهاز؟ | يدوياً عبر SSH | التطبيق تلقائياً |
| التوفر | فقط عند المحادثة | 24/7 بدون تدخل |
| السرعة | بطيء (ذهاب وإياب يدوي) | فوري وتلقائي |
| الخصوصية | البيانات تمر عبر طرف ثالث | يمكن تشغيل AI محلياً |
| التعرف على الجهاز | يدوي في كل مرة | تلقائي من أول اتصال |

### هل يحتاج Docker؟

```
┌─────────────────────────────────────────────────────────┐
│  Agent (على الجهاز البعيد)                             │
│  → تطبيق Electron عادي يعمل في الخلفية                │
│  → لا Docker — خفيف جداً                              │
│  → يدعم Windows وLinux                                 │
├─────────────────────────────────────────────────────────┤
│  Backend Server (الخادم المركزي)                       │
│  → Docker Compose ✅ للنشر بأمر واحد                   │
│  → docker compose up -d                                │
│  → مناسب لـ self-hosted وللخادم المركزي                │
├─────────────────────────────────────────────────────────┤
│  Dashboard (لوحة التحكم + AI Chat)                     │
│  → تطبيق ويب — يفتح في أي متصفح                       │
│  → لا تثبيت مطلوب على جهازك                           │
└─────────────────────────────────────────────────────────┘
```

## ثاني عشر: النقاش المفصّل للأجزاء الثلاثة

> *سيتم تحديث هذا القسم تدريجياً خلال جلسات النقاش التفصيلي*

### الجزء الأول — Agent (الجهاز البعيد) ✅ مكتمل النقاش

**ما هو؟**
البرنامج الذي يُثبَّت على الجهاز الذي تريد التحكم فيه. هو الجسر بين الجهاز والعالم الخارجي.

**القرارات المتفق عليها:**

| القرار | الخيار |
|--------|--------|
| وضع التشغيل | مزدوج — صامت في الخلفية + واجهة رسومية تُفعَّل عند الحاجة |
| من يثبّته؟ | أجهزة المالك + أجهزة آخرين (مشاركة رابط تثبيت) |
| صلاحيات التحكم | كامل — أوامر + ملفات + شاشة (كأنك جالس أمام الجهاز) |

**مهامه الكاملة:**
- فتح نفق اتصال آمن للسيرفر المركزي
- تنفيذ الأوامر الواردة (PowerShell / Bash)
- نقل الملفات في الاتجاهين (SFTP)
- بث الشاشة والتحكم الكامل بها (VNC/RDP)
- إرسال حالة الجهاز لحظياً (CPU, RAM, Disk, Network)
- إعادة الاتصال تلقائياً عند الانقطاع
- دعم نظام الاتصال متعدد الطبقات (Relay → Cloudflare → ngrok → Bore → LAN)
- إدارة المفاتيح والأمان محلياً

**واجهته:**
- وضع صامت افتراضي (يعمل في الخلفية بدون أي نافذة)
- Tray Icon اختياري (أيقونة في شريط النظام)
- شاشة حالة قابلة للتفعيل (الاتصال، معلومات الجهاز، سجل الجلسات)
- إعدادات بسيطة (السيرفر، الاسم، نوع الاتصال)
- مثبّت سهل بنقرة واحدة لغير التقنيين

---

### الجزء الثاني — السيرفر المركزي (Backend + Relay + AI) ✅ مكتمل النقاش

**ما هو؟**
القلب النابض للمنظومة. يربط الأجهزة البعيدة بواجهة التحكم ويشغّل الذكاء الاصطناعي.

**القرارات المتفق عليها:**

| القرار | الخيار |
|--------|--------|
| مكان تشغيل السيرفر | مزدوج — self-hosted على VPS أو cloud، المستخدم يختار |
| مصدر نموذج الذكاء الاصطناعي | مرن — المستخدم يختار بين OpenAI / Gemini / نموذج محلي |
| صلاحيات AI على الأجهزة | تحكم كامل — ينفذ كل شيء بدون تأكيد (وضع الخبير) |

**مهامه الكاملة:**
- استقبال اتصالات الأجهزة (Agent) وتسجيلها وإدارتها
- استقبال طلبات المتحكم (Dashboard / Mobile / API)
- Relay Engine — توجيه الاتصالات بأمان بين الأطراف
- AI Engine — تفسير الطلبات وتحويلها لأوامر وتحليل النتائج
- دعم نماذج AI متعددة (OpenAI, Gemini, Ollama المحلي)
- إدارة المستخدمين والصلاحيات والمجموعات
- تسجيل الجلسات والتدقيق الكامل (Audit Log)
- إرسال الإشعارات (Telegram + Web Push)
- تشغيل نظام الاتصال متعدد الطبقات وإدارة الاحتياطيات

**نموذج النشر:**
- Self-hosted: `docker compose up -d` على أي VPS
- Cloud: خادم مركزي جاهز للاستخدام الفوري بدون إعداد

---

### الجزء الثالث — واجهة التحكم (Dashboard + AI Chat) ✅ مكتمل النقاش

**ما هو؟**
ما تراه وتستخدمه يومياً. الواجهة التي تجعل كل شيء سهلاً وبديهياً.

**القرارات المتفق عليها:**

| القرار | الخيار |
|--------|--------|
| تصميم واجهة AI Chat | مرن — المستخدم يختار ما يظهر (شات / Terminal / مراقبة) |
| منصة الوصول | كل المنصات — ويب + Desktop + موبايل بنفس التجربة |
| أول شيء يظهر عند الدخول | لوحة مراقبة شاملة (حالة كل الأجهزة دفعة واحدة) |

**مكوناتها الكاملة:**

**شاشة الدخول الرئيسية (Overview Dashboard):**
- حالة كل الأجهزة المتصلة دفعة واحدة (متصل / منقطع / تحذير)
- مؤشرات فورية لكل جهاز (CPU, RAM, Disk, Network)
- تنبيهات ذكية بارزة (جهاز انقطع، استخدام مرتفع، محاولة دخول)
- وصول سريع للجهاز بنقرة واحدة

**صفحة الجهاز (Device Workspace) — مرنة وقابلة للتخصيص:**
- لوحات قابلة للإظهار/الإخفاء حسب الحاجة:
  - AI Chat (المحادثة مع الجهاز بالعربي أو الإنجليزي)
  - Terminal تفاعلي (SSH مباشر في المتصفح)
  - مراقبة فورية (CPU/RAM/Disk/Network بيانياً)
  - شاشة الجهاز المباشرة (VNC/RDP)
  - مدير الملفات (رفع/تنزيل/تصفح)

**صفحات الإدارة:**
- إدارة الأجهزة والمجموعات
- إدارة المستخدمين والصلاحيات
- سجل الجلسات والتدقيق الكامل
- إعدادات AI (النموذج، اللغة، الصلاحيات)
- إعدادات الاتصال (نوع النفق، الأولويات)

**التوفر عبر المنصات:**
- Web Dashboard (متصفح — لا تثبيت)
- Desktop App (Windows / Linux / macOS)
- Mobile App (Android / iOS)
